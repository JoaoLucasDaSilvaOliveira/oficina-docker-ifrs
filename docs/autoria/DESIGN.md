# Direção visual e conteúdo

Site estático em HTML, CSS e JavaScript para GitHub Pages. Navegação superior e percurso lateral permanecem visíveis. A área central é uma apresentação para projeção: título direto, explicação curta e desenho que ajude a entender uma ideia por tela.

## Hierarquia

O conceito é o elemento principal. Diagramas mostram relações concretas: processo e kernel; imagem e camada gravável; host e bind; contexto, estágios e cópia de artefatos; navegador, frontend, API e banco. Um desenho é preferível a blocos decorativos ou listas redundantes. Textos de agenda, tecnologias, duração e orientação do apresentador não disputam a tela com a explicação.

Comandos são acessórios de prática. Um botão reconhecível com ícone de terminal abre diálogo com o bloco, copiar e explicações das flags. A janela pode ter rolagem própria; o slide nunca depende de rolagem. Código extenso pertence à consulta, não ocupa o centro por padrão.

## Interface

A barra superior conserva Comandos e Materiais. O percurso lateral organiza capítulos e permite voltar a uma experiência. Os controles de avançar e voltar ficam fixos nas mesmas posições. Se o conceito não couber em uma tela com fonte legível, ele é dividido em mais telas.

Cada etapa oferece somente o arquivo necessário. O catálogo Materiais reúne os demais downloads, conteúdos dos ZIPs e destinos de extração. Não repetir cartões grandes de download em todo slide. O site é a porta de entrada da oficina; não exige Docker, pull ou login para ser lido.

## Linguagem

Público misto de ensino médio, ensino superior e comunidade. Precisão acadêmica com linguagem simples. A tela ajuda o aluno a acompanhar o argumento; o instrutor dá a explicação minuciosa em voz alta e os guias oferecem aprofundamento.

Go é um arquivo com soma; Vue é o template original Vite. O conteúdo de programação é deliberadamente pequeno. O mural com três serviços só aparece no Compose. A apresentação não exige estudo do código dessa aplicação para entender rede e persistência.

## Acessibilidade

Fontes locais, contraste legível em projeção, foco visível, botões com rótulos e símbolos acompanhados de nomes acessíveis. Diagramas usam textos e estrutura além da cor. Navegação e diálogos funcionam por teclado; Esc fecha a janela e o foco retorna ao controle que a abriu. Respeitar movimento reduzido.

Flags preservam o texto original para copiar e selecionar. O significado depende do comando receptor e pode ser consultado por mouse, toque e foco. Somente uma explicação aparece de cada vez, sem cobrir os controles de navegação.
